# 表格

表格是模板中最容易出问题的部分，这一份样例覆盖对齐、表头底色、边框与横向滚动。

## 基本表格

| 元素 | 用途 | 状态 |
| :--- | :--- | :---: |
| 标题 | 建立内容层级 | 完成 |
| 代码块 | 展示命令与程序 | 完成 |
| 引用 | 补充说明 | 完成 |
| 表格 | 罗列结构化数据 | 进行中 |

## 三种对齐

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 文本 | 文本 | 12 |
| 较长一些的文本 | 较长一些的文本 | 3456 |
| 短 | 短 | 7 |

## 宽表格

窗口较窄时，下面这张表应当可以横向滚动，而不是把整个页面撑宽。

| 命令 | 参数 | 默认值 | 说明 | 依赖 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `md` | `markdown` | 无 | 需要转换的 Markdown 文件路径 | pandoc | 必填 |
| `md` | `--template` | `github` | `templates/` 下的模板目录名称 | 无 | 可选 |
| `md` | `--no-open` | `false` | 只转换并打印 HTML 路径 | 无 | 可选 |
| `md-open.py` | `--template` | `default` | 直接调用脚本时的默认模板 | 无 | 与 CLI 不同 |
